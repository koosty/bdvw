
## Agent skills

### Issue tracker

Issues are tracked in bd (beads), a local-first CLI tracker: create with `bd create` / `bd q`, pick up work with `bd ready` / `bd update <id> --claim`, finish with `bd close <id>`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, label string equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
